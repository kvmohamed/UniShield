# UniShield — Model Card

## Model Overview
- **Name**: UniShield Threat Detection Models
- **Version**: v1.0.0 (to be trained in Phase 5)
- **Type**: Ensemble of rule-based, statistical, and ML models

## Intended Use
- Passive threat detection in unidirectional network traffic
- Research and laboratory environments only

## Training Data
- To be populated after Phase 5 training

## Evaluation Metrics
- Precision, Recall, F1-Score
- PR-AUC, False Positive Rate
- Detection Latency
- Confidence Calibration

## Limitations
- Models are trained on public datasets and may not generalise
- Metadata-only analysis has inherent blind spots
- Requires per-environment threshold tuning
